# Retro Icebreakers

Mini-jeux d'icebreaker pour rétrospectives d'équipe — multi-device, présentiel, TV.

> Documentation complète (structure, commandes, guide de test) à venir au fil du build.

## Démarrage rapide

```bash
npm install
npm run dev
```

- Front : http://localhost:4200
- API/WS : http://localhost:3000
